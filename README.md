CS 320 Portfolio Reflection

#1. I can make sure my code works correctly by testing it and checking that it meets the requirements. In my projects, I used Java and JUnit to create unit tests that checked different situations, including invalid inputs and missing information. Testing helps me find problems early and fix them before they cause bigger issues. I also need to think about security by validating user input and making sure the program handles errors properly.

#2. I interpret user needs by carefully reading the requirements and figuring out what the program needs to do. I then use those requirements to guide how I write and test my code. For example, when working on the contact service, I had to make sure contacts could be added, updated, and deleted while following the requirements. Breaking the requirements into smaller tasks helped me understand what needed to be done.

#3. When designing software, I like to break the problem into smaller parts so it is easier to understand and manage. I focus on making sure each class has a clear purpose and that the code is easy to test and maintain. These projects helped me understand how important testing is when developing software. As I continue learning computer science, I want to improve my programming skills and use what I have learned to create reliable software, especially games.
